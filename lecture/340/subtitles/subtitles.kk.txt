Қайырлы күн, құрметті студенттер. Сіздерді осы курстың кезекті әрі қорытынды дәрісінде көргеніме қуаныштымын. Бұл дәрісте біз AWS емтиханы туралы кеңірек айтып, емтиханға жақсырақ дайындалу үшін қосымша ақпарат көздерін қарастырамыз. Ендеше, бастайық. Бұл дәріс екі бөлімнен тұрады. Бірінші бөлімде AWS Solutions Architect Associate емтиханында сізден не талап етілетіні туралы толығырақ талдаймыз. Сондай-ақ осы емтиханға дайындалуға арналған қолжетімді ақпарат көздерін қарастырамыз. Екінші бөлімде біз сіздер үшін қосымша ақпарат көздерін қарастырамыз, олар тікелей емтиханмен байланысты болмаса да, бұлттық технологиялар мен нақты AWS бойынша біліміңізді тереңдету үшін пайдалы болады. Бүгінгі сессиямыздың бірінші бөлігін бастайық. Біз AWS Solutions Architect емтиханының домендерінен бастаймыз. Ол төрт бөлікке бөлінген. Әр бөлімнің өз салмағы бар, яғни қандай көлемде сұрақтар сол доменнен келетіні анықталады. Бірінші домен – қауіпсіз архитектураларды құру. Бұл тақырып бойынша шамамен 30% сұрақ келеді. Екіншісі – тұрақты және икемді архитектураларды құру. Салмағы шамамен 26%. Үшіншісі – жоғары өнімді архитектуралар – 24%. Соңғысы – Cost-Optimized, яғни бұлтта шығынды тиімді басқаруға негізделген архитектураларды құру. Бұл тақырып бойынша шамамен 20% сұрақ келеді. Енді әр доменді жеке-жеке кеңірек талдайық. Бірінші домен үш бөліктен тұрады. Бірінші бөлігінде AWS ресурстарына қауіпсіз қолжетімділік беру бойынша біліміміз тексеріледі. Мұнда тексерілетін сервис, ресурс атауларын және ұғымдарды тізіп өтейін. Бұл – AWS IAM, AWS Organizations, AWS Control Tower, Service Control Policies, IAM қолданушылар, топтар, рөлдер, policy. AWS жаһандық инфрақұрылымы туралы білім – бұл availability зоналар мен өңірлер. Содан кейін – principle of least privilege, Shared responsibility model, Root қолданушысын баптау бойынша best practices. Екінші бөлімде қолданбалар мен жүктемелер қауіпсіздігін баптау біліміміз тексеріледі. Қандай сервистер мен ұғымдар қолданылатынын және не үшін қолданылатынын жалпы түсінуіңіз қажет. Сервистер: Amazon Cognito, Amazon GuardDuty, Amazon Macie, VPC, AWS Shield, AWS WAF, AWS Secrets Manager. VPC-дегі ресурстар: security топтары, route tables, Network ACL, NAT Gateway, public және private subnets және т.б. Үшінші бөлімде біздің деректер қауіпсіздігі бойынша біліміміз тексеріледі. Яғни, тыныштықтағы деректерді шифрлау – AWS KMS сервисі. Деректерді тасымалдау кезінде шифрлау – AWS Certificate Manager (ACM). Сондай-ақ, деректерге қолжетімділік policy-н баптау, өмірлік циклді баптау және қауіпсіздікпен қамтамасыз ету тексеріледі. Шифрлау кілттерімен жұмыс істеу және сертификаттарды жаңарту. Келесі домен екі бөліктен тұрады, екінші бөлігінде масштабталатын және әлсіз байланысқан архитектураларды құру біліміміз тексеріледі. Қандай сервистер мен ұғымдармен таныс болу қажет екенін атап өтейік. Біріншіден, API құру және басқару – Amazon API Gateway сервисі. Managed сервис ұғымы және оларды қай кезде қолдану керек екенін түсіну. Кэштеу стратегиялары, микросервис архитектураларды құру принциптері, оқиғаға бағытталған архитектураны түсіну, горизонталды және вертикалды масштабтау айырмашылықтарын түсіну, Content Delivery Network (CDN) жұмыс принциптерін түсіну, жүктемені теңестіру принциптері – Application Load Balancer сервисі, көпдеңгейлі архитектуралар – frontend, backend, дерекқор деңгейі және т.б. Кезектер және хабар алмасу концепциялары – SNS және SQS сервистері. Serverless технологиялар ұғымы – AWS Fargate, Lambda, DynamoDB және т.б. Сақтау түрлерінің айырмашылықтарын түсіну – объектілік, файлдық, блоктық. Контейнер оркестрациясы – Amazon ECS, Amazon EKS сервистерімен жалпы танысу, read replica қашан және не үшін қажет екенін түсіну. Workflow оркестрациясы – AWS Step Functions сервисі. Екінші бөлігінде жоғары қолжетімді және fault-tolerant архитектураларды құру біліміміз тексеріледі. Сервистер мен ұғымдарға келсек – AWS жаһандық инфрақұрылымын білу. Яғни, availability зоналар, AWS аймақтары, Amazon Route 53 сервисі. Amazon Comprehend, Amazon Polly, T-Managed Services сервистерін жалпы түсіну. Route table-дарды баптау, негізгі DR стратегияларды білу: Backup and Restore, Pilot Light, Warm Standby, Active and Active Failover. RPO және RTO ұғымдары, жүктемені теңестіру концепциялары – Application Load Balancer. Деректерді сақтау сипаттамалары – сенімділік, репликация, қолжетімділік. Үшінші домен бес бөліктен тұрады. Бірінші бөлімде біз мәліметтерді сақтау бойынша масштабталатын және жоғары өнімді шешімдер құру біліміміз тексеріледі. Бұл Amazon S3, Amazon EFS, Amazon EBS сервистеріне қатысты, сондай-ақ объектілік, файлдық және блоктық сақтау түрлері бойынша білім тексеріледі. Екінші бөлімде есептеу ресурстары бойынша тиімді және икемді шешімдер құру біліміміз тексеріледі. Ең алдымен бұл EC2 сервисіне қатысты, қандай instance типтері мен топтары бар, олар немен ерекшеленеді. Содан кейін берілген трафик немесе бизнес талаптарға сәйкес есептеу қуатын дұрыс таңдай білу қабілеті тексеріледі. Сондай-ақ Amazon EC2 Auto Scaling және AWS Auto Scaling сервистері бойынша жалпы білім тексеріледі, олардың айырмашылықтары қандай. Serverless технологиялармен байланысты сервистер – AWS Lambda және AWS Fargate. Сондай-ақ контейнер оркестрациясымен байланысты сервистер – Amazon ECS және Amazon EKS. Үшінші бөлімде деректер мен дерекқорлармен байланысты жоғары өнімді шешімдер құру біліміміз тексеріледі. Кэштеу стратегиялары, Read Replica, Multi-AZ Failover сияқты ұғымдар, дерекқор түрлерін ажырату – serverless, реляциялық, реляциялық емес, in-memory білім қажет. Amazon RDS, Amazon Aurora, Amazon DynamoDB, Amazon ElastiCache сервистері бойынша жалпы түсінік қажет. Төртінші бөлімде желілік бөлім бойынша білім тексеріледі. Сервистер: Amazon CloudFront, AWS Global Accelerator, AWS VPN, Elastic IP және Direct Connect. Бесінші бөлім – деректермен жұмыс істеу бойынша білім тексеріледі. Бұл аналитика және визуализация сервистері: Amazon Athena, AWS Lake Formation, Amazon QuickSight. Егер деректер тасымалдау сервистері туралы айтсақ – AWS DataSync және AWS Storage Gateway. Деректерді түрлендіруге арналған сервис – AWS Glue, ал деректерді стримингке жіберетін сервис – Amazon Kinesis. Төртінші, соңғы домен төрт бөлімнен тұрады. Бірінші бөлім – бұлттағы сақтау шығындарын оңтайландыру туралы. Атап айтқанда: AWS Organizations арқылы Multi-Account Billing, Cost Allocation Tags сияқты функционал білімдері қажет. Шығындарды басқару сервистері – AWS Cost Explorer, AWS Budgets, AWS Cost and Usage Report. Сондай-ақ сақтау сервистерін білу қажет: Amazon FSx, Amazon EFS, Amazon S3, Amazon EBS. Блоктық сақтау түрлері: HDD және SSD – олардың айырмашылықтары мен ерекшеліктері. Сонымен қатар, Amazon S3 ішіндегі сақтау кластарын білу, олардың айырмашылығы, әрқайсысы қай кезде қолданылады – осы білім қажет. Екінші бөлім – есептеу ресурстарының шығындарын оңтайландыру. Есептеу қуатын сатып алу опциялары: Spot Instances, Reserved Instances, Savings Plans – олардың айырмашылықтары мен қолдану ерекшеліктері. EC2 сервисі бойынша білім: instance типтері, instance отбасылары – айырмашылықтары мен қолдану жағдайлары. Оңтайлы instance өлшемін таңдау, масштабтау стратегиялары (Auto Scaling, hibernation). Үшінші бөлім – дерекқор шығындарын оңтайландыру: Amazon RDS, Aurora, DynamoDB және Redshift сервистерімен байланысты. Төртінші бөлім – желілік шығындарды оңтайландыру. Ең алдымен – VPC сервисі мен ондағы ресурстарға, сондай-ақ VPC-пен интеграцияланатын ресурстар мен сервистерге қатысты. Енді AWS Certified Solutions Architect Associate емтиханының ресми парақшасына көшейік. Іздеу жүйесінде "aws saa exam" деп жазсақ жеткілікті. Бірінші жарнамасыз нәтиже – бізге қажетті сілтеме. Оны басқан соң Solutions Architect Associate емтиханының басты парақшасына өтеміз. Бұл парақшада емтихан туралы пайдалы ақпарат көп, парақшаның төменгі жағында тілді өзгерте аласыз. Мен екі бөлімге нақтырақ тоқталғым келеді. Бірінші бөлім – парақша ортасындағы оң жақтағы “Exam overview” бөлімі. Мұнда емтиханның негізгі ақпаратын көресіз: деңгейі – Associate, ұзақтығы – 130 минут. Сіз ағылшын тілін ана тілі ретінде пайдаланбайтындықтан қосымша 30 минут ала алатыныңызды еске саламын. Сіз сондай-ақ емтиханның қазіргі құнын көре аласыз, жазу сәтінде ол 150 доллар. Формат туралы айтсақ – бұл 65 сұрақ, олардың ішінде 4 нұсқадан бір дұрыс жауабын таңдау керек немесе 5 және одан да көп нұсқадан бірнеше дұрыс жауапты белгілеу керек. Сіз сондай-ақ қазіргі уақытта осы емтиханды тапсыруға болатын тест провайдерлері туралы ақпаратты көре аласыз. Келесі бөлім – бұл екі сілтеме бар секция. Бірінші сілтеме – Exam guide, екіншісі – Sample questions. Алдыңғы слайдтарда біз емтихан домендері туралы айтқан кезде дәл осы Exam guide құжатын қолдандық. Сіз бұл құжатты өзіңіз жүктеп алып, толығырақ таныса аласыз. Екінші құжат – бұл sample questions. Онда емтихан сұрақтарына барынша ұқсас 10 сұрақ бар. Мен бұл құжатпен танысуды соңына қалдыруды ұсынамын – сіз толық дайын болған кезде, әр сұраққа 2 минуттан бөліп, жалпы 20 минут ішінде осы мини-емтиханды тапсырып көруіңіз керек. Уақытқа үлгердіңіз бе, жоқ па – соған міндетті түрде назар аударыңыз және өз нәтижеңізге қараңыз. Егер 7 немесе одан көп сұраққа дұрыс жауап берген болсаңыз, онда сіз емтихан тапсыруға дайынсыз. Exam guide – өте жақсы құжат, қосымшаларында да пайдалы ақпарат бар. Ол үш бөліктен тұрады және мен оның барлық бөліктерін толық зерттеуге кеңес беремін. Бірінші бөлімде емтиханда келуі мүмкін технологиялар мен концепциялар сипатталған. Екінші бөлімде емтиханда келуі мүмкін сервис тізімі бар, сондықтан әр сервис бойынша өтіп, олардың мәнін екі сөйлеммен түсіндіре алуыңыз қажет. Бұл сирек кездесетін сервистер бойынша сұрақтарға дұрыс жауап беру үшін жеткілікті болады. Үшінші бөлім – емтиханда келмейтін сервистердің тізімі. Сондықтан осы тізімді қасыңызда ұстауға кеңес беремін – оны басып шығару немесе қағазға жазып қою – артық уақыт жоғалтпау үшін пайдалы болады. Енді негізгі сервистерге келсек – оларға не істеу керек? Олар үшін әрбір негізгі сервис парақшасына кіріп көруді ұсынамын. Мысалы, S3 сервисі үшін іздеу жүйесіне AWS S3 деп жазыңыз. Бірінші жарнамасыз сілтеме – бізге керек сілтеме. Парақша ашылған соң, әрбір негізгі сервиске арналған өте ұқсас парақшаларды көресіз. Мен Overview, Features және FAQ бөлімдерімен танысуды ұсынамын – бұл сервистер бойынша жиі қойылатын сұрақтар. Осы слайдта терең зерттеу ұсынылатын ең негізгі алты сервис көрсетілген. Осылайша, бүгінгі дәрісіміздің бірінші бөлімін аяқтадық, онда біз AWS Solutions Architect Associate емтиханына тікелей қатысты ақпарат көздерін қарастырдық. Бүгінгі дәрістің екінші бөлімінде біз емтиханға тікелей қатысы жоқ, бірақ AWS пен бұлтты технологиялар туралы жалпы түсінік беретін ақпарат көздерін қарастырамыз. Ең бірінші және маңызды сілтеме – AWS құжаттамасына сілтеме. Қажетті сілтемені слайдтың төменгі жағынан көре аласыз. Келесі сілтеме – AWS Cloud Adoption Framework, сілтеме слайдтың төменгі жағында. Келесі сілтеме – AWS Quick Starts негізгі парақшасы. Бұл парақшада AWS бұлтында белгілі бір шешімді орнататын 500-ден астам CloudFormation скрипті бар. Сілтеме слайдтың төменгі жағында көрсетілген. Және соңғы сілтеме – бұл Getting Started парақшасы, бастау үшін қолдануға болатын парақша. Парақшаның төменгі жағынан кез келген қолжетімді тілде ашуға болады. Мұнда негізгі ақпарат беріледі және сілтемелер арқылы AWS туралы қызықты тақырыптарды қосымша оқи аласыз. Осылайша, бүгінгі дәрісіміз аяқталды. AWS ресми емтиханына дайындық үшін пайдалы әрі тегін ақпарат көздерін және жалпы AWS пен бұлтты технологиялар туралы түсінік беретін ресурстарды қарастырдық. Бүгінгі дәріс – біздің үлкен курстың соңғы дәрісі. Қатысқандарыңыз үшін рахмет, ақпарат сіздерге пайдалы және қызықты болды деп сенемін. AWS емтиханын тапсыруды жоспарлағандарға – сәттілік тілеймін. Қалғандарыңызға – бұл білім мен дағдылар алғашқы жұмысыңызды табуға көмектессін. Мүмкін армандағы жұмысты тауып, болашақта осы білімді сәтті қолданып, жақсы нәтижелер көрсетесіз. Сіздермен кездескеніме қуаныштымын. Біз байланыста боламыз, толық ақпаратты топтық чаттардан аласыздар. Кездескенше!
