Қайырлы күн, құрметті студенттер. Зертханалық жұмысты шолу сессиясында сіздерді көргеніме қуаныштымын. Бүгінгі зертханалық жұмыстың тақырыбы — Amazon CloudFront сервисін пайдаланып, динамикалық контентті стримингтеу. Ендеше, бастайық. Біз AWS Academy-дегі Cloud Architecting курсының басты парақшасынан бастаймыз. Мұнда сол жақтағы навигациялық мәзірді пайдаланып, Modules бөлімін таңдауымыз қажет. Модульдер тізімінен бізді қызықтыратыны — 11-модуль Caching content және мұнда Guided Lab белсенділігі бар. Сол батырманы басайық және зертханалық жұмыстың басты парақшасына өтейік. Мұнда, көріп тұрғанымыздай, екі терезе бар — зертханалық жұмыс тапсырмасы бар терезе және терминал. Зертханалық жұмысты шолу аясында терминал бізге қажет емес, сондықтан оны жасырып қоюымызға болады. Осы зертханалық жұмыста біз динамикалық контентті Amazon CloudFront сервисі арқылы кэштеуді жүзеге асырамыз. Біздің жағдайда контент — HLS форматындағы мультибитрейтті стрим болады. Бұл стримді кез келген смартфон браузерінде ашуға болады. Сондай-ақ, біз Amazon Elastic Transcoder сервисімен танысамыз, ол арқылы дайын видеоны бірнеше битрейтпен HLS форматына түрлендіреміз. Зертханалық жұмыстың соңында біз AWS бұлтындағы келесі архитектураны аламыз. Бастапқыда дайын MP4-видео файлын S3 бакетке жүктейміз. Содан кейін бұл S3 бакетті Amazon Elastic Transcoder сервисінде дереккөзі ретінде қолданамыз. MP4-файлын HLS форматына түрлендірген соң, дайын файлдарды екінші S3 бакетке жүктейміз. Кейін CloudFront осы екінші S3 бакетті пайдаланушылардың смартфондарына динамикалық контент стримингтеу көзі ретінде қолданады. Бұл зертханалық жұмысты орындауға ұсынылатын жалпы уақыт — 30 минут. Естеріңізге саламын, біз бұл зертханалық жұмыс аясында уақытша құрылған AWS аккаунтында жұмыс істейміз, сондықтан барлық сервистер қолжетімді болмайды. Біз тек осы зертханалық жұмыста қолданылатын сервистермен шектелеміз. Зертханалық жұмысты бастау үшін алдымен уақытша AWS аккаунтын құруды инициализациялау қажет. Ол үшін экранның оң жақ жоғарғы бөлігіндегі Start Lab батырмасын басу керек. AWS аккаунты дайын болғанын көрсететін хабарлама шыққан соң, қалқымалы терезені жауып, Start Lab батырмасының жанындағы AWS батырмасын басуға болады. Бізді AWS Management Console басты парақшасына бағыттайды. Біз зертханалық жұмыстың бірінші тапсырмасына көшеміз. Мұнда екінші тапсырмаға қажет AWS ресурстары мен файлдарының бар екенін тексеру қажет. Алдымен бізге S3 сервисіне өту қажет. Ол үшін сервис іздеу жолын қолданып, S3 деп жаза бастаймыз. Шыққан тізімде S3 сервисі бірінші болып тұрады. Соған өтейік. Содан кейін S3 бакеттер тізімінен атауында awstrainingreinvent сөзі барын табуымыз керек. Тапқан соң, оның ішін ашып, мазмұнын тексереміз. Сіз бакет ішінде Input атты папка барын көресіз. Сол папканы ашып, ішін қарайық. Ішінде AmazonS3Sample.mp4 атты видеофайл болуы керек. Егер бұл файл болмаса, 10 минут күтіп, парақшаны жаңартып көріңіз. Егер сіз видеофайлды көрсеңіз, келесі тапсырманы орындауға көше аласыз. Екінші тапсырмада бізге CloudFront Distribution құру қажет болады. CloudFront Distribution-ды біз динамикалық контентті, атап айтқанда HLS форматындағы мультибитрейтті видеофайлды кэштеу мен жеткізу үшін қолданамыз. Distribution жасау үшін алдымен CloudFront сервисіне өтуіміз қажет. Сервистерді іздеу жолағына CloudFront деп жаза бастайық. Сервиске өткен соң, оның басты парақшасын көреміз. Ол жерден Create CloudFront Distribution батырмасын тауып, басу керек. Бізді жаңа Distribution жасау парақшасына бағыттайды. Мұнда Origin Settings бөлімінде бірнеше өзгерістер енгізу қажет болады. Origin Domain деген жерде бакеттер тізімін ашып, атауында awstrainingreinvent сөзі бар S3 бакетті таңдаймыз. Содан кейін Origin Access өрісінде Public таңдаңыз, ал Web Application Firewall өрісінде Do Not Enable Security Protections опциясын таңдаңыз. Назар аударыңыз, біз Custom SSL Certificate өрісін толтыру қажет екені туралы қызыл хабарламаны көреміз. Бұл қауіпсіздік тұрғысынан ұсыныс қана, бұл өрісті толтыру міндетті емес. Сондықтан бұл зертханалық жұмыс аясында оны елемей, парақшаны соңына дейін айналдырамыз. Төменгі оң жақ бөлігінде Create Distribution батырмасы болады. Сол батырманы басайық және CloudFront Distribution жасайық. Біз үшінші тапсырмаға көшеміз, бұл тапсырмада Amazon Elastic Transcoder сервисінде pipeline баптаймыз. Бұл тапсырма бірнеше бөлімге бөлінген. Бірінші бөлімде pipeline-ды жасаймыз. Ол үшін сервис іздеу жолағын пайдаланып, Elastic Transcoder сервисіне өтеміз. Содан соң, S3 бакетіміздің деректері сақталған аймаққа кіргенімізге көз жеткізуіміз керек. Әдетте бұл North Virginia болады. Қажетті аймаққа ауысқаннан кейін, pipeline парақшасында Create a new pipeline батырмасын басамыз. Бізді жаңа pipeline жасау парақшасына бағыттайды. pipeline name өрісіне InputPipeline деп жазамыз. Содан соң Input bucket өрісінде атауында awstrainingreinvent сөзі бар S3 bucket таңдаймыз. IAM Role ретінде AmazonElasticTranscoderRole таңдаймыз. Бұл зертханалық жұмыс үшін арнайы жасалған рөл, ол Elastic Transcoder сервисіне S3 bucket-ке қол жеткізуге мүмкіндік береді. Содан кейін келесі ұзын атаулы бөлімге дейін парақшаны айналдырамыз — Configuration for Amazon S3 bucket for transcoded files and playlists. Мұнда Bucket өрісіне біздің S3 bucket-ті таңдап, Storage Class ретінде Standard көрсету қажет. Төменірек басқа бөлім болады, ол Configuration for Amazon S3 bucket for thumbnails деп аталады. Мұнда да Bucket өрісіне біздің S3 bucket-ті таңдап, Storage Class ретінде ReducedRedundancy көрсету қажет және парақшаның соңына дейін айналдырыңыз. Экранның төменгі оң жағында Create pipeline батырмасы болады. Батырманы басып, pipeline жасайық. Біз үшінші тапсырманың екінші бөліміне өтеміз. Мұнда job құрамыз. Бұл — дәл сол pipeline элементі, ол видеомызды бір форматтан басқа форматқа түрлендіреді. Pipelines тізімі бар парақшада Create new job батырмасын басу қажет. Жаңа job жасау парақшасы ашылады. Мұнда Pipeline ретінде InputPipeline көрсету қажет. Одан кейін Output key prefix өрісіне output/ деп көрсету қажет. Бұл префикс жасалған медиа файлдарды S3 бакетке сақтау үшін қолданылады. Келесі Input key өрісі үшін видео файлыңызды таңдау қажет болады. Job жасауды жалғастырамыз. Төменірек орналасқан бөлімге өтіп, мұнда битрейт параметрлерін көрсетеміз. Бұл зертхана жұмысында біз үш битрейт құрамыз: 2, 1.5 және 1 мегабайт секундына. Әр битрейт үшін жаңа бөлім ашып, сол бөлімде әр битрейтке қатысты мәліметтерді енгізу қажет болады. Енді, 2 мегабайт/сек битрейт мысалында не істеу керектігін көрейік. Preset өрісіне System preset: HLS 2M таңдаймыз, Segment duration ретінде 10 секунд, ал Output key ретінде HLS20M көрсетеміз. Бұл префикс жасалған сегменттер үшін қолданылады. Содан кейін Add another output батырмасын басу қажет болады, жаңа бөлім қосылады және HLS 1.5M және HLS 1M пресеттері үшін де дәл сол әрекеттерді қайталау қажет. Біз үшінші тапсырманың соңғы бөлігіне жеттік және мұнда плейлист баптауларын көрсетеміз. Playlists (Adaptive Streaming) бөліміне дейін айналдырып, Add playlist таңдап, келесі мәндерді енгіземіз. Master playlist name өрісі үшін primary деп көрсетеміз, Playlist format ретінде HLSv3 таңдау қажет, сәл төменірек жоғарыда бапталған үш битрейтті де таңдау керек. Содан кейін парақшаның соңына дейін айналдырып, Create new job батырмасын басуға болады. Job шамамен екі минут ішінде орындалады. Біз соңғы төртінші тапсырмаға жеттік және мұнда динамикалық контентпен стримді тестілеу жүргіземіз. Оны тестілеу үшін кез келген смартфон қажет болады. Ең алдымен URL құру қажет. URL екі бөліктен тұрады. Бірінші бөлік — CloudFront Distribution URL, содан кейін S3 bucket-ті тауып, Elastic Transcoder сервисі жасаған медиа файлдар сақталған папканы ашу қажет. Сонымен, алғашқы бөліктен бастайық. Сервис іздеу жолағын пайдаланып, CloudFront сервисіне өту қажет. Таратылымдар тізімінен өз distribution-ді ашып, статусы In progress-тен Enabled-ке ауысқанын тексеріңіз. Содан кейін distribution URL-ін көшіріп, оны мәтіндік редакторға сақтаймыз. Енді соңғы URL-дің екінші бөлігін алу қажет. Ол үшін сервис іздеу жолағын пайдаланып, S3 сервисіне өту қажет. Бізді awstrainingreinvent атауы бар S3 bucket қызықтырады. Бұл bucket ашылған соң Output папкасын ашып, primary.m3u8 файлын табу қажет. Соңғы URL үшін осы файлға дейінгі жол пайдаланылады, яғни /output/primary.m3u8. Бұл жолды CloudFront Distribution URL-іне қосайық. 38-қадамда соңғы URL мысалын табуға болады. Енді осы URL-ді смартфоныңызда ашу қажет. Смартфонда сілтемені ашқан бойда видеоплеер пайда болады және онда видео ойнай бастайды. Интернет байланысына байланысты видеоплеер автоматты түрде сәйкес битрейтке ауысады. Егер интернет жылдамдығы жоғары болса, бейне жоғары сапада көрсетіледі. Егер интернет байланысы әлсіз болса, видеоплеер автоматты түрде төмен рұқсаттағы бейнеге ауысады. Осылайша, зертханалық жұмыстың барлық тапсырмаларын орындадық. Elastic Transcoder және Amazon CloudFront сервистерімен жұмыс жасау тәжірибесін алдық. Осылайша, біз Amazon CloudFront сервисі арқылы динамикалық контентті кэштеу және тарату жұмысын баптадық. Енді автобағалау скриптін іске қосу қажет. Қажетті батырма зертханалық жұмыстың басты парақшасындағы оң жақ жоғарғы бұрышта орналасқан. Егер қажетті ұпайларды жинасаңыз, зертханалық жұмысты аяқтауға болады. Егер жоқ болса, белгілі бір тапсырмаға қайта оралып, өзгерістер енгізіп, скриптті қайта іске қосуға болады. Зертханалық жұмысты аяқтау үшін экранның оң жақ жоғарғы бөлігіндегі End Lab батырмасын басып, әрекетті растау қажет. Содан кейін зертханалық жұмыс парақшасын жабуға болады. Осымен, зертханалық жұмысқа шолуымызды аяқтаймыз. Назарларыңызға рахмет. Келесі белсенділіктерде кездескенше!
