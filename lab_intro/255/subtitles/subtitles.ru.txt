Давайте теперь подробнее пройдемся по второму заданию, здесь нам необходимо создать NAT Gateway во второй availability зоне. А именно мы будем создавать NAT Gateway в Public Subnet. Давайте теперь пройдемся по третьему заданию, здесь необходимо будет создать Bastion Host в одной из Public Subnets. Bastion Host или Jump Server - это EC2 инстанс, находящийся в VPC и доступный для подключения из интернета по SSH. Далее уже от этого инстанса можно подключаться к Application Server. Bastion Host - это первый уровень защиты и благодаря нему вы не сможете, либо мошенники не смогут подключиться из интернета напрямую к вашим Application Server. Согласно заданию мы выбираем любой из Public Subnets. Далее создаем EC2 инстанс с названием Bastion Host, как AMI указываем Amazon Linux 2023 AMI, как Instance type указываем t2.micro, как Key pair указываем vockey, его мы можем скачать из главной страницы лабораторной работы. Далее нам необходимо поставить галочку в поле Auto-Assign Public IP и также создать Security группу такую, которая разрешает подключение по SSH вашему конкретному IP-адресу. Давайте теперь подробнее остановимся на четвертом задании, здесь мы будем создавать Launch Template. В рамках инициализации временного AWS аккаунта для нас был создан кастомный AMI от сервера CafeWebAppServer. Мы будем его использовать в нашем Launch Template. Таким образом во время создания Launch Template нам необходимо указать как AMI - Cafe WebServer Image. Далее как Instance type необходимо указать t2.micro, как Key pair необходимо создать новую, так как для обеспечения дополнительной безопасности важно, чтобы SSH ключи от наших Application серверов отличались от SSH ключа Bastion Host. Далее как Security группу выбираем CafeSG, в настройках тегов необходимо указать как Key - Name, как Value - webserver и поставить галочку, чтобы эти теги также создавались для новых EC2 инстансов и самое последнее необходимо выбрать CafeRole для IAM Instance Profile. Теперь давайте подробнее рассмотрим пятое задание. Здесь мы будем создавать Auto Scaling group, согласно заданию необходимо будет выбрать Launch Template созданный на предыдущем задании. Как VPC укажем LabVPC, Subnets это Private Subnet 1 и 2, далее мы должны указать размеры ASG Desired и Minimum capacity как 2 и Maximum capacity - 6. Далее необходимо будет настроить Target tracking scaling policy, он будет смотреть на метрику Average CPU Utilization, Target value необходимо указать 25 и Instances need 60. Как только мы его создадим, нам необходимо перейти на список инстансов и посмотреть, что создалось 2 инстанса с соответствующими названиями. Давайте теперь подробнее остановимся на шестом задании. Чуть ниже в настройках сети необходимо будет создать новую security группу и эта security группа должна разрешать HTTP трафик из интернета. Далее необходимо создать новую target группу и пока мы не будем регистрировать таргеты для этого Load Balancer, как только мы создадим Load Balancer необходимо дождаться пока статус Load Balancer не станет Active. Как только наш Load Balancer будет готов, нам необходимо будет произвести изменения в настройках Auto Scaling group и привязать его к Load Balancer. Напоминаю, что мы не привязываем ASG напрямую к Load Balancer, а делаем это через target группу.
